# Demo script: three minutes, target 2:30

Open beforehand: the War Room (crewfund.vodka), a terminal in `api/` with the checker command
typed, and a backup recording on both laptops.

| Time | Screen | Say |
| --- | --- | --- |
| 0:00–0:15 | War Room | "This is THE CREW, an AI hedge fund. Five agents, each a strategy with a persona, backtested from 2017 to the holdout cutoff. The fund against the S&P 500, the Mastermind's capital split, and every agent's red-team badge." |
| 0:15–1:15 | + NEW AGENT | Hand the keyboard to the judge: "Describe any strategy." While stages stream: "Gemini compiles your words into a recipe; it never sees a return. Now a nine-year walk-forward backtest, net of costs. Now the red team: lookahead, shuffle, 2020, 2022." Land on the new agent's page and its first message. |
| 1:15–1:45 | Agent chat | Ask "What did the Red Team find?" then "Why did you sit out in 2022?" Point at the EVIDENCE footer: "Those are rows from its own log, not words from the model." |
| 1:45–2:05 | War Room | "Who runs the money": scrub months. "The Mastermind pays by trailing Sharpe and fires agents whose picks keep losing to the market." Show a fired or cut agent. |
| 2:05–2:25 | Terminal | Run the organizers' checker against api.crewfund.vodka: 100/100. "The judged endpoints use the organizers' own math, and they never import Gemini." |
| 2:25–2:30 | War Room | "Nothing on this screen is invented. THE CREW, crewfund.vodka." |

Fallbacks: if Gemini is down, creation shows a readable error, so recruit with the backup
recording; chat still answers from stored rows. If the venue Wi-Fi fails, play the recording.
